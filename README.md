# MuX — сайт и документация

Официальный сайт приложения **MuX** (muxolotl.github.io/VKMuX) и сопутствующая документация.

Исходный код самого приложения закрыт; здесь публикуются:

- `site/` — статический сайт (GitHub Pages). Чистый HTML + CSS + JS, без сборки и внешних CDN.
- `docs/` — документация API.
- `.github/workflows/deploy-pages.yml` — автодеплой сайта при пуше в `main`.
- `.github/workflows/release.yml` — сборка релизов из закрытого репозитория с исходниками и публикация их здесь.

## Сайт

Полностью самодостаточный: шрифты лежат в `site/fonts/`, стили — `site/css/styles.css`, логика — `site/js/main.js`. Ничего не подключается с внешних CDN.

Ссылки на скачивание берутся из `site/releases.json` — файл обновляется автоматически при каждом релизе.

## Релизы

Релиз запускается вручную (workflow *Release*):

1. Версия и changelog синхронизируются в репозитории с исходниками.
2. Сборки под Windows, macOS и Linux публикуются в Releases этого репозитория.
3. Генерируется `latest.json` для встроенного автообновления.
4. Обновляется `site/releases.json` на сайте.
