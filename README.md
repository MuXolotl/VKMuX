# MusiMuX

Музыкальный десктоп-клиент. Работает полностью локально — без внешних серверов.

## Что умеет

- Авторизация по логину/паролю (с поддержкой 2FA и капчи) или по токену
- Библиотека, плейлисты, поиск, рекомендации, популярное
- Текст песни — караоке для синхронизированных, статика для остальных
- Системный трей с управлением воспроизведением
- Мини-плеер у трея (по клику на иконку)
- Настраиваемое поведение при закрытии окна (спрашивать / трей / выход)
- Перемешивание, повтор (все / один), горячие клавиши
- Автообновления с GitHub Releases (уведомление / автоматически / вручную — на выбор)

## Скачать

Готовые сборки — на странице [Releases](https://github.com/MuXolotl/VKMuX/releases)
или на [сайте проекта](https://muxolotl.github.io/VKMuX/).

> вручную (SmartScreen на Windows, Gatekeeper на macOS).
