Возможности

Всё, что нужно для VK Музыки

Полноценный клиент с авторизацией, библиотекой, поиском и текстами. Работает локально — никаких промежуточных серверов.

Авторизация

По логину/паролю (с 2FA и капчей) или по токену. Полная эмуляция Android-клиента.

Библиотека и плейлисты

Полная библиотека, плейлисты, поиск, рекомендации, популярное. Добавление и удаление треков.

Тексты песен

Караоке-режим для синхронизированных текстов. Статичный текст для остальных.

Системный трей

Мини-плеер у трея, управление воспроизведением, настраиваемое поведение при закрытии.

Плеер

Перемешивание, повтор (все / один), горячие клавиши, упреждающая подгрузка.

Полностью локально

Никаких промежуточных серверов. Весь код открыто. Токены хранятся только на вашем ПК.

Технологии

Под капотом

Современный стек. Rust-ядро без внешних VK SDK. Tauri 2 для оболочки. Svelte 5 для UI.
