Сборки без цифровой подписи. При первом запуске Windows SmartScreen или macOS Gatekeeper могут попросить подтверждения — это нормально. Обновления устанавливаются автоматически, с проверкой подписи обновлений.

Как установить

Пара минут — и готово.

Windows
  1. Скачайте установщик .msi (или .exe) и запустите его.
  2. Если SmartScreen показывает предупреждение — нажмите «Подробнее» → «Выполнить в любом случае». Приложение не подписано сертификатом, поэтому Windows перестраховывается.
  3. Следуйте шагам установщика. Готово — MuX появится в меню «Пуск».
macOS
  1. Скачайте .dmg и откройте его.
  2. Перетащите MuX в папку «Программы».
  3. При первом запуске Gatekeeper может заблокировать приложение: нажмите «Отмена», затем откройте его через контекстное меню → «Открыть» (или «Системные настройки → Конфиденциальность и безопасность → Открыть всё равно»).

Не знаете, какой у вас Mac? В меню Apple → «Об этом Mac»: чип Apple (M1–M4) — берите Apple Silicon, иначе — Intel.

Linux

.deb (Debian, Ubuntu, Mint и другие): 

sudo apt install ./*.deb

AppImage — без установки, просто сделайте файл исполняемым и запустите:

chmod +x MuX-*.AppImage
./MuX-*.AppImage
