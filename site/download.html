Сборка из исходников

Если предпочитаете собрать сами:

1.
Установите Rust (stable), Node.js 20+ и системные зависимости Tauri
2.
Клонируйте репозиторий: 
git clone https://github.com/MuXolotl/VKMuX.git
cd VKMuX
3.
Установите зависимости и соберите: 
npm ci          # Зависимости фронтенда
npm run tauri:dev     # Dev-режим (hot reload)
npm run tauri:build   # Продакшен-сборка
